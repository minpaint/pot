# Анализ: Перенос функций из Админки во Фронтенд

## Контекст

Система OT_online имеет обычных пользователей-организаций (bplus, palata, biomilk, mobipart, sfera) с `is_staff=False`, которые входят через фронтенд, но не имеют доступа к Django-админке. Задача — определить, каких функций им не хватает на фронтенде, и приоритизировать их перенос.

## Что ОТСУТСТВУЕТ на фронтенде (нужно переносить)

### ПРИОРИТЕТ 1 — Критично для работы организации

#### 1.1 Импорт/Экспорт данных
- **Проблема:** Пункт меню виден только `is_staff`. Обычный пользователь не может импортировать сотрудников из Excel, экспортировать данные.
- **Что в админке:** `GlobalImportAdmin`, `RegistryImportAdmin` — импорт сотрудников, оборудования, структуры через XLSX.
- **Что сделать:** Добавить во фронтенд раздел импорта/экспорта для своей организации (без суперадмин-функций). Убрать проверку `is_staff` из пункта меню или создать упрощённую фронтенд-версию.
- **Файлы:** `directory/admin/global_import_admin.py`, `directory/admin/registry_import_admin.py`, `directory/resources/`

#### 1.2 Управление структурой (Подразделения и Отделы) ✅ РЕАЛИЗОВАНО
- **Проблема:** Пользователь не может добавить/изменить подразделение или отдел своей организации — всё только через суперадмина.
- **Реализовано:** `directory/views/structure.py` — полный CRUD подразделений и отделов.
  - URL: `/directory/structure/` — страница структуры
  - URL: `/directory/structure/subdivisions/create/` — создание подразделения
  - URL: `/directory/structure/subdivisions/<pk>/update/` — редактирование
  - URL: `/directory/structure/subdivisions/<pk>/delete/` — удаление
  - Аналогично для отделов (`departments/`)
- **Меню:** Раздел "Организация" → "Структура"

#### 1.3 Каталог СИЗ (создание новых позиций) ✅ РЕАЛИЗОВАНО
- **Проблема:** Пользователь может выдавать только те СИЗ, что уже есть в каталоге. Добавить новую позицию — только через суперадмина.
- **Реализовано:** `SIZCreateView`, `SIZUpdateView`, `SIZDeleteView` в `directory/views/siz.py`.
  - URL: `/directory/siz/create/` — создание СИЗ
  - URL: `/directory/siz/<pk>/update/` — редактирование
  - URL: `/directory/siz/<pk>/delete/` — удаление
- **Меню:** Раздел "Организация" → "Каталог СИЗ"

---

### ПРИОРИТЕТ 2 — Важно для полноценной работы

#### 2.1 Управление должностями — расширение
- **Проблема:** Базовый CRUD есть, но нет управления нормами СИЗ для должности (inline в админке) и вредными факторами.
- **Что в админке:** Inline-редакторы `SIZNormInline`, `PositionMedicalFactorInline` внутри `PositionAdmin`.
- **Что сделать:** На странице должности во фронтенде добавить вкладки/секции: «Нормы СИЗ» и «Вредные факторы» с возможностью добавления/удаления.
- **Файлы:** `directory/admin/position.py`, `directory/admin/mixins/position_attributes.py`

#### 2.2 Смена пароля ✅ РЕАЛИЗОВАНО
- **Реализовано:** URL `/directory/auth/password-change/` с Django-стандартным `PasswordChangeView`.
- **Меню:** Выпадающее меню профиля → "Сменить пароль"

#### 2.3 Управление токенами доступа к экзаменам
- **Что сделать:** Простая страница во фронтенде — список токенов по своей организации, создание нового, копирование ссылки.

## Что оставить ТОЛЬКО в Админке (суперадмин-функции)

| Функция | Обоснование |
|---------|-------------|
| Управление организациями | Создание/удаление организаций — суперадмин |
| Профили пользователей | Настройка прав доступа — суперадмин |
| Шаблоны документов (DOCX) | Загрузка шаблонов — суперадмин (технически сложно, риски) |
| Шаблоны email | Системные настройки — суперадмин |
| Пункты меню (MenuItem) | Настройка системы — суперадмин |
| Логи отправок (полные) | Только чтение суперадмином |
| Создание квизов/вопросов | Можно оставить в админке (сложный интерфейс) |
| Типы/программы обучения | Справочник — суперадмин |
| Настройки email | Системные параметры — суперадмин |
